# Support development

FreeCAD Codex Sidebar is an experimental open-source project. The most useful
support today is testing with sample documents, reporting reproducible bugs,
improving documentation and contributing reviewed fixes. See the
[contribution guide](../CONTRIBUTING.md) to get started.

Financial sponsorship is not currently available. If it opens, this page will
link to the official funding channel and explain how support helps maintain
the project, test FreeCAD compatibility and cover development model usage.

Sponsorship would be optional. The source and installation instructions remain
available under the project's license.
